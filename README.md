# DeskCanvas 桌面画布

把桌面变成一块可编辑的画布 —— 记事本、表格、贴图以卡片形式贴在壁纸之上的桌面层（普通窗口之下），平时像壁纸的一部分安静待着，切回桌面就能看；一键进入编辑模式就能改。

- **不是**置顶便签：锁定模式下沉在桌面层、鼠标完全穿透，不挡桌面图标
- **不是**代码型小组件：对比 Übersicht（写 JS）/ Rainmeter（写皮肤配置），DeskCanvas 是所见即所得拖拽编辑
- 首版平台：macOS；技术路线：Go + Wails + 一小块 Darwin 原生层（窗口层级）
